# WhisPaste Scoop Bucket

[Scoop](https://scoop.sh) bucket for **WhisPaste** — cross-platform dictation: hotkey, speak, paste anywhere.

```powershell
scoop bucket add whispaste https://github.com/whispaste/scoop-bucket
scoop install whispaste
```

Update:

```powershell
scoop update whispaste
```

The manifest is auto-updatable (`checkver`/`autoupdate`) and tracks the latest
GitHub release of [`whispaste/whispaste`](https://github.com/whispaste/whispaste).
